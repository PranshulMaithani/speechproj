================================================================================

Casual Conversations is a public read-vs-spontaneous corpus:
    scripted     -> label 1  (read-aloud = cheat-analog)
    nonscripted  -> label 0  (spontaneous = genuine)
    555 scripted + 1727 nonscripted English clips.

Used as its OWN batch (batch='casual'), group_ids in the CC_NNNNN namespace.

Paths assume:
    repo     = ~/speech3
    data dir = /home/ubuntu/nn/data
    runs dir = /home/ubuntu/nn/runs
Adjust if yours differ.

--------------------------------------------------------------------------------
HOW TO READ THE RESULT
--------------------------------------------------------------------------------

* casual_selftest F1 = ceiling of read-vs-spontaneous separability on clean
  public data. If this is high (>0.9) but audios6 is ~0.76, the gap is the
  CLIENT being hard, not the task being hard.

* allstar_selftest F1 = same ceiling on a different public corpus. Compare to
  casual_selftest: if both high, the approach is sound and the audios6 gap is
  purely domain shift (which the v2 work targets).

* These two are CAPABILITY checks, run once. For the deployment iteration loop
  (closing the audios6 gap), keep casual + ALLSTAR as --train_only_batches and
  keep testing on audios6. Don't fold them into the deployment eval -- it
  blends "public-corpus performance" with "client performance" and muddies the
  domain-gap analysis.
